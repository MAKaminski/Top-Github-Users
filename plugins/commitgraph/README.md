# Commitgraph — Claude Code plugin

Packages the Commitgraph MCP server as an installable add-in, so Claude gains the dataset's twelve
tools, five prompts and four resources without anyone pasting a URL.

```
/plugin marketplace add MAKaminski/Top-Github-Users
/plugin install commitgraph@commitgraph
```

## What it installs

- **An MCP server** (`.mcp.json`) — the hosted, public, read-only endpoint at
  `https://top-github-users-amber.vercel.app/api/mcp`. No authentication, no credentials, no local
  process. Set `COMMITGRAPH_MCP_URL` to point the plugin at a different deployment, such as a local
  `next dev` on `http://localhost:3000/api/mcp`.
- **A skill** (`skills/commitgraph/`) — when to reach for the dataset, which tool answers what, and
  the four properties of the data that make an answer wrong if ignored.

## Why the server is remote rather than bundled

The tools read a snapshot that is regenerated by a scheduled crawl. Bundling a local server would
either ship a copy of the data that goes stale the moment it is installed, or require a Node
process and a checkout on every machine. The hosted endpoint means an install is a URL, and every
user is reading the same snapshot the site is.

Nothing is sent to the server beyond the tool arguments themselves — it has no write surface, no
credential store, and no access to the calling machine.
